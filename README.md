# Nix VM for Cybersecurity

[![built with nix](https://builtwithnix.org/badge.svg)](https://builtwithnix.org)

Inspired by [this post](https://jeancharles.quillet.org/posts/2023-01-16-Basic-nix-vm-for-just-anything.html)

## Usage

To spin up the VM using [**just**](https://github.com/casey/just)

```bash
just run
```

- Username: `guest`
- Password: `guest`

You can also clean the VM using

```bash
just clean
```
